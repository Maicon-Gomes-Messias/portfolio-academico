# AED II — Algoritmos e Estruturas de Dados II

Trabalhos da disciplina de **Algoritmos e Estruturas de Dados II** (Engenharia de
Computação, PUC Minas), nos semestres **2020/2** e **2021/1**.

## Prática em Java

- **`pratica-java/introducao-a-linguagem-java/`** — três exercícios de introdução à
  linguagem: cálculo de aumento salarial (`q1.java`), média e situação do aluno
  (`q2.java`) e comparação de medições (`q3.java`).
- **`pratica-java/vetores-e-matrizes/`** — correção de prova a partir de um gabarito,
  com vetores (`vetor.java`), e manipulação de matriz para encontrar o maior e o menor
  valor (`App.java`).

```bash
# exemplo: rodar o exercício da matriz
javac -d bin pratica-java/vetores-e-matrizes/*.java
java -cp bin App
```

## Trabalhos teóricos

Listas e trabalhos escritos, em `trabalhos-teoricos/`, organizados por semestre:

| Semestre | Assuntos |
| --- | --- |
| **2020/2** | Recursividade, redirecionamento de entrada e saída, argumento do método `main`, referências e apontadores |
| **2021/1** | Somatório |

Os temas são os que a disciplina cobra: complexidade de algoritmos, somatórios,
contagem de operações, estruturas lineares (listas, pilhas, filas), árvores binárias de
busca e AVL, tabelas hash, e métodos de ordenação e de busca.
