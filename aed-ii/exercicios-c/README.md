# AED II — Exercícios em C

Exercícios de **Algoritmos e Estruturas de Dados II** (Engenharia de Computação,
PUC Minas), escritos em **C**.

| Arquivo | O que faz |
| --- | --- |
| `palindromo.c` | Lê palavras até a entrada `FIM` e informa `SIM` ou `NAO` se cada uma é um palíndromo, ignorando maiúsculas/minúsculas e espaços |
| `cifra-de-cesar.c` | Cifra de César: desloca as letras do texto por um número fixo de posições |

> No envio original na disciplina, os arquivos estavam sem a extensão `.c`. Aqui eles
> foram renomeados para `palindromo.c` e `cifra-de-cesar.c`, para ficarem identificáveis
> como código-fonte em C.

## Como compilar e executar

```bash
gcc -o palindromo palindromo.c
./palindromo
```

```bash
gcc -o cifra-de-cesar cifra-de-cesar.c
./cifra-de-cesar
```

Exercícios acadêmicos, com finalidade didática.
